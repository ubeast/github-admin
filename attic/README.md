# attic/

Retired / backup assets kept for reference. **Nothing here is used by the
package, the docs site, or CI.** It's outside `docs/`, so GitHub Pages never
serves it, and the sdist's explicit `include` list (see `pyproject.toml`)
leaves it out of the published package. It *is* tracked in git, so it's
backed up to the remote and recoverable — that's the whole point of the
folder versus `drafts/` (which is gitignored and local-only).

exists, what it draws, output sizes, the fonts it needs (gitignored via
